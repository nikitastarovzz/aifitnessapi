# Ten changes from the search data — 2026-10-27

The owner asked for ten changes drawn from Search Console and Bing that can be
done without them, then said "build all … implement and merge" (2026-10-27).
Binding like the other plans: facts only from primary sources fetched in the
writing session, evidence files for snapshot-sourced pages, gates green, no
`updated` stamp moved without a full re-check.

## Data

Google, 2026-09-27 to 2026-10-24 (`data/gsc/snapshots/2026-10-27.json`): 197
clicks, 19,450 page-level impressions (previous window 181 / 16,944). Bing, same
window: 30 clicks, 1,260 impressions. Page × country was read once from the
Search Console API for this plan, not committed.

- **US:** 29% of impressions, 0.45% CTR at average position 12.9, against
  1.36% at 8.7 for the rest. The hubs and the homepage rank far worse in the US
  (homepage 42 vs 20), and so do /fitness-apis/wearable-data-apis (26 vs 11)
  and /fitness-apis/ai-workout-tracking-apis (35 vs 12).
- **Bare vendor queries rank 25–60:** garmin api 38 impressions @45, strava api
  29 @56, apple healthkit 20 @61, whoop api 13 @34, fitbit api 10 @58, while
  long-tail questions about the same vendors rank 4–10.
- **Zero-click pages in the top 10:** 26 pages with 80+ impressions, position
  ≤10.5, CTR under 1.2%.
- **Generated reference sections nobody finds:** HealthKit identifiers 117 of
  128 pages with no impressions, Bluetooth GATT 39 of 45, Wear OS data types 25
  of 26, workout types 14 of 14, Google Health API 34 of 50. 72 hand-written
  pages published before 2026-09-10 have no impressions either.
- **Bing** gives 2.4% CTR to Google's 1.0% and ranks the hubs (/fitness-apis
  @4.3, nutrition APIs @5.9).
- **Brazil** is the second country by impressions (730), but only about 40 of
  them carry a page with a disclosed query; most are anonymised.

## The ten

| # | Change | Part |
|---|---|---|
| 1 | Route mis-ranked queries to the page that owns them (links, anchors, FAQ hand-offs) | 1 |
| 2 | One target page per vendor for the bare "<vendor> api" query | 1 |
| 3 | Rewrite titles and descriptions on the zero-click top-10 pages; log them in ops/gsc/retitled.txt | 1 |
| 4 | Index only what earns it: a data-driven noindex rule for generated pages, fold or noindex old zero-impression pages | 1 |
| 5 | US-first ordering: the pages with the widest US gap go first in 1–3 | 1 |
| 6 | Pricing and alternatives pages for Withings, Samsung Health, Suunto, COROS, Wahoo, Dexcom, where their pages support one | 1 |
| 7 | Head-to-heads: Apple Vision vs MediaPipe, ML Kit vs MediaPipe, ExerciseDB vs API Ninjas; rewrite garminconnect vs garth | 1 |
| 8 | Stop hubs and index pages soaking up head queries; noindex /opensearch.xml | 1 |
| 9 | Bing-favoured hubs get comparison tables and direct Q&A; answer surfaces point at the money pages | 1 |
| 10 | A Portuguese (pt-BR) edition of the money pages with hreflang, its own sitemap and translation-freshness gates | 2 |

Part 1 ships as one pull request built by five agents in separate worktrees
(1+2+3+5, 4+8, 6, 7, 9). Part 2 starts after Part 1 merges, so it translates
final text.
