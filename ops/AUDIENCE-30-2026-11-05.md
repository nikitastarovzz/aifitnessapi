# Thirty big builds for the people who come here — 2026-11-05

The owner asked (2026-11-05) to read the data, understand who visits and what
else they would want, then research, build, implement and merge thirty big
things. Binding like the other plans: CLAUDE.md, ops/GEO.md, primary sources
fetched in the writing session, gates green, no added running cost (every tool
runs in the browser or is generated at build time), KinesteX only where
relevant and always disclosed. Built in waves after ops/MORE-30-2026-11-05.md
so parallel builds do not fight over the same files and disk.

## Who comes (disclosed Google + Bing queries, Oct 4–31, 3,874 impressions)

| Audience | Share of classified | What they search |
|---|---|---|
| Wearable / health-data integrators (backend + mobile devs) | ~40% | Garmin, Oura, WHOOP, Terra, HealthKit, React Native HealthKit, OAuth, webhooks |
| Exercise & nutrition content builders | ~10% | ExerciseDB, exercise video API, workout API |
| Pose / computer-vision engineers | ~6% | MediaPipe vs MoveNet, YOLO pose, OpenPose BODY_25, RTMPose licence |
| Founders / PMs building a fitness app | ~6% | "fitness app builder" (92), "ai fitness", sleep/workout app development |
| Gym & clinic B2B software | ~6% | gym GDPR, Cliniko vs HealthKit, Glofox API, member engagement |
| Python hobbyists / self-trackers | ~6% | garth, python-garminconnect, Garmin personal API |
| Compliance / legal / PM | ~3% | HIPAA covered entity, App Store guidelines |
| Hardware / BLE | ~2% | FTMS treadmill format, ANT+ vs Bluetooth |
| Researchers | <1% | Fitabase, Fitbit research after the turn-off |

Desktop is 87% of impressions (people at work); top countries US, Brazil,
India, UK, France, Germany. Clicks concentrate on buying pages and tools.
What they would also want: things that remove work — schemas, playgrounds,
code that runs, calculators, their own data, and a way to watch their stack.
