## What the data says (Google, Oct 28 – Nov 3; access confirmed working)

- Aggregator demand is the largest query group and earns nothing: "terra api
  alternatives" 120 impressions at 6.0, 1 click; "best aggregator for wearable
  and sensor integrations" 45 at 4.9, "best wearable health data aggregator"
  25 at 7.3, "best wearable health data api for developers" 19 at 7.8, all 0
  clicks. /alternatives/terra-alternatives: 328 impressions, 1 click. Those
  pages are in held cohorts, so the answer is a new tool, not a retitle.
- Clicks come from reference and pricing pages (exercise database, RTMPose,
  Garmin pricing, Halpe-26), i.e. developers with a concrete question.
- "Viral" for this audience means: original numbers others cite (HN, Reddit,
  newsletters), things people put in their README or post (badges, cards),
  and tools that answer an urgent question (the Fitbit Web API turn-off was
  Nov 2).
