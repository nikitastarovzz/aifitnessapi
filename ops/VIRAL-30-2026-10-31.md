# Thirty things built to be shared — 2026-10-31

The owner asked (2026-10-31) for "30 more to make the website go viral … big
things", then to plan, build and ship them. Binding like the other plans:
CLAUDE.md, ops/GEO.md, facts from primary sources fetched in the writing
session, gates green, no added running cost (owner's standing condition from
the same day), KinesteX mentioned only where relevant and always disclosed.

## What spreads in this niche, and why it shaped the list

- **A list people adopt as the record.** Killed by Google — an open-source
  list of discontinued Google products with launch date, shutdown date and a
  description, maintained on GitHub — was picked up by The Next Web, BGR and
  TechSpot within days of launch in March 2019
  ([TNW](https://thenextweb.com/news/killed-by-google-digital-obituary),
  [BGR](https://bgr.com/business/killed-by-google-products-list/)). Our
  `/changes` already holds dated, quoted deprecations; nobody keeps the
  fitness-API version of that list.
- **A result you can share without spoiling it.** Wordle's copyable emoji grid
  let people post a score without the answer; Smithsonian and others credit it
  for the spread ([Smithsonian](https://www.smithsonianmag.com/smart-news/heres-why-the-word-game-wordle-went-viral-180979439/)).
  Anything with a score here ships a copyable, spoiler-free result.
- **Hardware in the browser, nothing to install.** Web Bluetooth heart-rate
  demos keep getting written up because they work on the first click in
  Chrome; one 2026 write-up found a strap whose data had no real beat-to-beat
  variability, which made its HRV meaningless
  ([guyrutenberg.com](https://www.guyrutenberg.com/2026/04/04/web-hr-monitor-heart-rate-and-hrv-in-the-browser/)).
  That finding is a hook only a byte-level decoder can show.
- **Cost condition.** Every share card is drawn client-side on a canvas, not
  by a dynamic OG route; nothing stores user data; crowdsourcing goes through
  prefilled GitHub issues, which cost nothing.

## Build rules for this wave

- Zero added running cost: static or client-side only; no API routes, no
  dynamic OG routes, no storage, no new npm dependencies (runtime CDN loads
  pinned to versions verified on the registry, as in /tools/pose-benchmark).
- Every fact on a game or puzzle comes from data already in `src/data/` or a
  primary source fetched in the writing session; games never invent a vendor
  event. Synthetic or illustrative values are labelled.
- Share cards are canvas-drawn PNGs and copyable text; nothing is uploaded.
- KinesteX: a disclosed `KinestexNote` on 3 and 6 only (camera motion
  build-vs-buy); nowhere else in this wave.
- Camera, motion and Bluetooth data never leave the device, and each page says
  so where the permission is asked.
